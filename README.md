# Project_Guidelines

## Guidelines for DEB Project
Develop a responsive Web application - must use React, Tailwind, REST API, Express and MongoDB. <br> The application must be properly containerized using docker and the entire application should be capable of running with just a single Docker Compose command. <br> The project should be uploaded in GitHub. A readme file should be uploaded with the following details <br> Name of the Project <br> Short one-paragraph description about the application of the project <br> Step-by-step instructions for running the application <br> Documentation folder should contain <br> Detailed description of the project <br> Introduction: <br> Overview of the project. <br> Brief description of the problem the application addresses.<br>  Purpose and objectives of the project. <br> Project Scope: Definition of the boundaries of the project <br> Key features and functionalities of the project. <br> Functional Requirements: Detailed description of the features and functionalities. <br> Use cases and user stories. <br> Conclusion: Summary of the project requirements and objectives. <br> Workflow diagram of the use case<br> Future Enhancements <br> PPT for the final project presentation.<br> PPT should contain a minimum 5 slides.<br>  Working Demo of Application (A video/screen recording depicting the flow and functionalities of the application).

## Evaluation Criteria
Evaluation will be based on the following parameters: <br> How well can you implement the concepts in the project?<br> Whether the application is functional based on your design. <br> How well you know the technologies used for development <br> How well you will be able to explain the codes used in the project <br> How well did you perform in the project evaluation? <br> Additional Notes <br> The above-mentioned are a few general guidelines that we expect from your project. <br> However, there is no restriction on what more you can do. <br> Try to go the extra mile.
